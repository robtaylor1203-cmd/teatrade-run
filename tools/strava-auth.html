Strava → refresh token helper

One-time use. Get your Strava refresh token, then paste it into Cloudflare Pages env vars.

Step 1 — Create a Strava API app

Go to strava.com/settings/api and create an app:

  • Application Name: TeaTrade Run
  • Category: Visualizer
  • Website: https://run.teatrade.co.uk
  • Authorization Callback Domain: localhost (just for this helper — change later if you want)

You'll get a Client ID (a number) and Client Secret (long string).

Step 2 — Authorize this helper to read your runs

This opens Strava in a new tab. After you click "Authorize" you'll be redirected back to localhost with a code=... in the URL — copy that whole URL into the field below.

Step 4 — Add to Cloudflare Pages

In your Pages project → Settings → Environment variables, set these (Production):

STRAVA_CLIENT_ID       = (the Client ID number)
STRAVA_CLIENT_SECRET   = (the Client Secret)
STRAVA_REFRESH_TOKEN   = (the refresh_token from above)
STRAVA_ATHLETE_ID      = (the athlete_id from above — used for the profile link)
STRAVA_SINCE           = 2026-01-01   (or whatever date you want to start counting from)
